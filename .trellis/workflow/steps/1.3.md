# 1.3 配置上下文 `[required · once]`

## 目标

为实现和检查 agent 策选最小且完整的 spec/研究上下文。仅完整档执行；普通档跳过（`context_ready` gate 对缺失的 manifest 视为通过，子代理会 fallback 读 `prd.md`）；极简档不适用。

## 执行动作

在任务目录维护 `implement.jsonl` 和 `check.jsonl`，每行一个 JSON object：

```json
{"file": ".trellis/spec/<package>/<layer>/index.md", "reason": "相关规范"}
```

- `implement.jsonl` 放实现所需 spec 和研究。
- `check.jsonl` 放检查所需 spec，尤其是质量规范。
- 不放代码文件或即将修改的文件。
- 需要时可使用：

```bash
python3 ./.trellis/scripts/task.py add-context <task-dir> implement <path> "<reason>"
```

## 产物与状态

- 两个 manifest 已按实际任务范围完成策选。

## 验证标准

```bash
python3 ./.trellis/scripts/task.py validate <task-dir>
```

中央 gate 必须确认 manifest 合法、路径存在且没有占位内容。
