## 必需条件

| 条件 | 是否必需 |
|---|:---:|
| 存在 `prd.md` | 是 |
| 用户确认进入实现 | 是 |
| `task.py start` 已成功运行 | 是 |
| `task.json.status = in_progress` | 是 |
| `research/` 有产物（复杂任务） | 按任务判断 |
| `design.md` / `implement.md`（复杂任务） | 按任务判断 |
