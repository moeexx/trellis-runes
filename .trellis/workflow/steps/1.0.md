# 1.0 创建任务 `[required · once]`

## 目标

为需要 Trellis 跟踪的工作创建任务目录，但不提前进入实现阶段。

## 前置条件

- 已按请求分类确认本次需要创建 Trellis task。
- 当前没有可复用的 active task；如已有 active task，跳过创建。

## 执行动作

```bash
python3 ./.trellis/scripts/task.py create "<task title>" --slug <name>
```

`--slug` 只填写可读名称，不要带 `MM-DD-` 前缀，命令会自动添加。任务树先创建父任务，再按需使用 `--parent` 创建子任务。

只运行 `create`，不要运行 `start`。`start` 会把任务切换到实现阶段，应留给 1.4。

## 产物与状态

- 新任务目录及 `task.json`、`prd.md` 等初始文件已创建。
- 任务保持 `planning` 状态。

## 验证标准

- `python3 ./.trellis/scripts/task.py current --source` 能定位新任务。
- 不因子任务存在而启动父任务；下一份可独立交付的工作应启动对应子任务。
