# 1.2 研究 `[optional · repeatable]`

## 目标

为实现或设计补充必要的仓库事实、第三方 API 资料和版本约束。

## 执行动作

- 研究可以在任意阶段进行，不限于本地代码。
- 使用 `trellis-research` agent 时，任务描述必须明确研究问题。
- 每个主题写入 `{TASK_DIR}/research/<topic>.md`，不要只在对话中返回结论。
- 研究文件记录查询范围、发现的文件/模式、外部参考、相关 spec 和限制条件。

## 产物与状态

- 复杂任务的 `research/` 包含可供后续实现和检查复用的研究文件。

## 验证标准

- 研究结论已落盘。
- 关键不确定性、版本约束和未找到的信息已明确标注。
