# 1.4 激活任务 `[required · once]`

## 目标

在规划产物完成并获得用户评审确认后，将任务切换到实现阶段。仅完整档、普通档执行；极简档没有任务，选定后直接进入 2.1。

## 执行动作

```bash
python3 ./.trellis/scripts/task.py start <task-dir>
```

命令会执行 `task_start` Central Gate。若失败，只修复命令返回的具体项后重试；在 gate 通过前保持 `planning`。

若出现会话身份错误，按命令提示设置会话身份后重试。

## 产物与状态

- `task.json.status` 从 `planning` 变为 `in_progress`。
- 当前会话开始接收实现阶段的 workflow-state 提示。

## 验证标准（完成标准，原 1.5）

| 条件 | 是否必需 |
|---|:---:|
| 存在 `prd.md` | 是 |
| 用户确认进入实现 | 是 |
| `task.py start` 已成功运行 | 是 |
| `task.json.status = in_progress` | 是 |
| `research/` 有产物（完整档） | 按任务判断 |
| `design.md` / `implement.md`（完整档） | 按任务判断 |

缺少必需条件时回到对应的 Phase 1 step 补齐，不提前实现。
